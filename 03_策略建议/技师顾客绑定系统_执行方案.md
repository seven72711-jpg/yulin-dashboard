# 十三绝 · 技师私定客户管理工具 执行方案

> 目标：帮技师管理自己的私定客户（疗程、定价、改善追踪），不碰基础按摩客户
> 团队：自研系统 + 自有开发团队

---

## 一、为什么要做——以及为什么不做全域CRM

### 1.1 两个客户群，两个完全不同的需求

| | 基础按摩客户 | 私定客户 |
|------|------------|---------|
| 占比 | 95%（~860人/月） | 5%（~50单/月） |
| 每次状况 | 不一样——这次肩痛下次腰痛 | 有明确的改善目标和疗程计划 |
| 需要记录的 | 力度偏好、怕疼部位、过敏 | 完整疗程进度、每次改善情况、定价方案 |
| 记录价值 | 低——下次痛点可能完全不同 | 高——疗程周期长，每次都和上次相关 |
| 谁的关系 | 来过几次但未必记住技师 | 高度绑定技师，技师定方案、定价格、定节奏 |
| 技师的动力 | 无所谓——这批客人随机分配 | 很强——这是技师自己的收入和品牌 |

### 1.2 结论

**不值得为基础按摩客户建系统。值得为私定客户建工具。**

而且这个工具的使用者是技师，不是门店。技师的私定客户是技师自己的资产——技师自己定疗程、自己定价格、自己维护关系。门店的角色不是"占有这个关系"，是"给技师提供工具，让她管得更好"。

### 1.3 现状痛点

目前林燕（全店私定第一）管私定客户的方式大概率是：微信聊天记录 + 脑子记 + 偶尔笔记本。客户多了必然漏——谁该做第几次了、上次调整了什么手法、这个疗程还剩几次。这些信息在技师脑子里，不在任何系统里。林燕请假一周，她的私定客户只能等她回来。

---

## 二、系统定位

不是门店CRM。是**技师的私定客户管理工具**。

| 维度 | 旧思路（全域CRM） | 新思路（技师工具） |
|------|-----------------|-------------------|
| 使用者 | 门店/前台 | 技师本人 |
| 对象 | 所有客户 | 仅私定客户 |
| 数据归属 | 门店 | 技师（客户授权后使用） |
| 关系定位 | 门店想"拥有"客户关系 | 门店帮技师"维护"客户关系 |
| 门店角色 | 管理者 | 工具提供者 |

## 三、功能模块

### 阶段一：私定疗程管理（MVP，1.5个月）

#### 3.1.1 疗程档案

技师为每个私定客户建一个疗程卡片：

| 字段 | 说明 | 输入 |
|------|------|------|
| 客户名 | 从收银系统自动匹配 | 自动 |
| 主诉问题 | 客户要解决什么（腰椎间盘突出/产后恢复/运动损伤...） | 技师选标签或语音 |
| 疗程方案 | 几次为一个疗程、频率（每周1次/每周2次） | 技师输入 |
| 定价 | 单次价格、总价 | 技师自定义 |
| 每次记录 | 日期、做了什么、改善情况、下次调整方向 | 语音一句话 |
| 疗程进度 | 第N次/共N次、剩余次数 | 自动计算 |

#### 3.1.2 技师操作流程

```
客户到店（私定预约） → 技师打开自己手机
    ↓
看到：王先生 | 腰椎康复疗程 | 第3次/共8次 | 上次：热敷+正骨，腰痛频率从每天降到隔天
    ↓
服务结束 → 语音记录："这次加了腰椎牵引，效果很好，建议保持每周2次的频率到第5次再评估"
    ↓
系统更新：疗程进度4/8，下次提醒时间自动生成
```

#### 3.1.3 技师主页

```
┌─────────────────────────┐
│ 林燕 | 我的私定客户       │
├─────────────────────────┤
│ 🔴 今天待服务（3人）     │
│  14:00 王先生 腰椎 4/8   │
│  16:30 李女士 产后 2/10  │
│  20:00 张先生 肩颈 5/6   │
├─────────────────────────┤
│ 🟡 本周内（8人）         │
│ 🟢 疗程进行中（21人）    │
│ ⚪ 已完成疗程（15人）    │
├─────────────────────────┤
│ [+ 新建私定客户]         │
└─────────────────────────┘
```

### 阶段二：疗程提醒与维护（1个月）

- 下次服务时间到了 → 提醒技师联系客户
- 疗程过半 → 提醒中期评估
- 疗程结束 → 提醒是否续疗程或转维护
- 客户超过2周未约 → 提醒跟进

### 阶段三：客户端小程序（可选）

私定客户扫码绑定后可以看：自己的疗程进度、每次记录、下次预约时间。但**归属权仍在技师**——客户看到的是"林燕为你定制的腰椎康复方案"，不是"十三绝的服务记录"。

---

## 四、隐私：比全域CRM简单得多

私定客户已经高度信任技师。授权不是"十三绝请求采集身体数据"，是**"林燕问你能不能帮她用手机记一下你的疗程进度"**。这两者完全不同。

授权流程：技师口头问→客户点头→技师手机录入。不需要前台参与，不需要扫码，不需要隐私协议弹窗。因为这不是门店系统，是技师自己的记事本。客户的数据只存在技师的账号里。

---

## 五、技术方案

在现有十三绝系统中加一个**技师私定模块**，技师登录自己的账号后可见。数据结构：

```
technician_id → client_list → treatment_plan → session_records
```

不需要收银系统对接（私定不走收银），不需要跨技师数据共享（私定是1对1关系），不需要离线缓存（技师手机有网络）。开发量大幅缩减。

| 模块 | 人天 |
|------|------|
| 私定疗程数据结构+API | 3-5 |
| 技师手机端（疗程管理+语音录入） | 10-15 |
| 提醒引擎 | 3-5 |
| 客户小程序（可选） | 5-8 |
| **合计** | **21-33人天** |

## 六、ROI

### 6.1 投入

| 项目 | 金额 |
|------|------|
| 开发 | ~5-8万（1-2人×5-6周） |
| **首年投入** | **~6万** |

### 6.2 预期收益

当前每月~50单私定（5.5%），5名技师能做。如果工具帮技师管理得更好：

| 效果 | 测算 |
|------|------|
| 疗程完成率提升 | 减少客户中途流失，+10%续疗程 |
| 技师效率提升 | 林燕当前21单/月，工具化管理后可能做到30+ |
| 新技师私定启动 | 有工具的技师更容易开始做私定 |
| **月增量** | ~10单私定 × ¥450 = ¥4,500/月 |
| **年增量** | ¥54,000 |

**ROI：首年投入6万，直接增量5.4万。核心价值不是直接营收，是帮现有私定技师管好她的客户资产。**

## 七、实施路线图

```
第1周：找林燕聊
  - 她现在怎么管私定客户的？（微信/笔记本/脑子）
  - 痛点在哪里？（客户多了记不住疗程进度？请假时客户怎么办？）
  - 给她看疗程管理原型，问她愿不愿意试

第2-4周：开发MVP
  - 技师手机端：疗程列表 + 单疗程详情 + 语音记录
  - 只给林燕一个人用

第5-6周：林燕试用
  - 录入她现有的21个私定客户
  - 收集每天使用频率、录入时间、她觉得缺什么

第7-8周：迭代 + 推给其他私定技师
  - 唐婉清、梁雪华、禤妮、姚梨
  - 目标：5名能做私定的技师都用上

第9周起：持续迭代
  - 提醒引擎
  - 客户小程序（可选）
```

## 九、不做的事

- ❌ 基础按摩客户的档案（每次痛点不一样，记了没用）
- ❌ 门店看所有客户数据（私定客户是技师的，不是门店的）
- ❌ 跨技师客户共享（私定是1对1关系）
- ❌ 复杂的隐私授权流程（技师口头问一句就够了）
