## 十、门店运转逻辑

```
平台拉新 → 首次体验 → 加微信/留印象 → 储值锁客 → 次月到店 → 指定关系 → 私定提价
    ↓          ↓           ↓           ↓          ↓         ↓         ↓
  43%客源   228均价      存手机号    61.4%完成  24.6%留存   点客率    均价¥450
  抽佣20%   75%下月不来   技师主动    办卡=承诺   复购池    指定客    5人能做
```

**真实复购数据（5→6月跨月追踪（最新））：**
- 5月641个有手机号的客户 → 6月158人回来 = **跨月留存率24.6%**
- 回头客人均¥477，是新客¥303的1.57倍
- 75.4%客户下个月不来了

**利润增长的真实路径：**
```
跨月留存24.6%→30% → 复购池扩大 → 指定关系建立 → 私定转化 → 客单价/净利率自然提升
                                                                    ↓
                       同时：复购客走直付 → 拉新需求降低 → 平台费自然缩减
```

### 核心矛盾（5→6月跨月验证）
- **75.4%客户下个月不再来**。门店月月换血3/4的客源，必须持续拉新才能维持营收
- 回头客人均消费¥477（新客¥303），留住一个老客的价值是新客的1.5倍+
- 12个技师仅4个做私定（占营收5.5%），私定的前置条件是指定关系，而指定靠复购积累
- 平台费高是果，留存率低才是因

### 利润杠杆（5→6月跨月验证）
1. **跨月留存率24.6%→30%**：每月多留≈35人，按人均¥477算≈¥1.7万增量，零获客成本
2. 首次体验→技师连接：加微信、记住偏好、邀约下次到店
3. 复购客→指定客→私定客：逐级转化，客单价从228→340→450
