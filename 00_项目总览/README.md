- **资金流向**：日常收银款 → 总部账户 → 月底结算扣除管理费/推广费后 → 转回门店用于发工资和分红

- **3月异常亏损**：薪酬改革过渡期，技师钻漏洞刷单，总部承担大部分亏损。漏洞已堵。
- **股东分红**：直接从门店账户转至股东个人账户
